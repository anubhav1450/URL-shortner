# 🔄 Overall Flow (high level)

2 hi main operations hain:

1. **Create short URL (POST)**
2. **Use short URL (GET / redirect)**

---

# 🧩 1. CREATE FLOW (Transaction samajh)

User bole:
👉 “ye URL short kar de”

---

## 🔹 Step-by-step

### 1. Request aata hai

```id="tfk2d7"
POST /shorten
{
  "url": "https://google.com"
}
```

---

### 2. Server kya karta hai?

👉 shortCode generate karega

```js id="hffyl3"
const shortCode = nanoid(6);
```

---

### 3. DB me save karega

```js id="8j5e4h"
{
  shortCode: "abc123",
  originalUrl: "https://google.com",
  visitHistory: []
}
```

---

### 4. Response bhejega

```id="ov9d2k"
http://localhost:3000/abc123
```

---

# ⚡ Short me

```id="v0hbpr"
URL → shortCode generate → DB save → return short URL
```

# 🧩 2. REDIRECT FLOW (real magic 🔥)

User open karta hai:

```id="p3cc17"
GET /abc123
```

---

## 🔹 Step-by-step

### 1. Server shortCode pakadta hai

```js id="4fa9av"
const code = req.params.shortCode;
```

---

### 2. DB me search

```js id="gdl6ay"
findOne({ shortCode: code })
```

---

### 3. Agar mil gaya

👉 2 kaam karega:

---

## ✅ (A) visitHistory update karega

```js id="p4yr8u"
visitHistory.push({ timestamp: Date.now() })
```

👉 (analytics ke liye)

---

## ✅ (B) redirect karega

```js id="rvd1pn"
res.redirect(originalUrl);
```

---

### 4. Agar nahi mila

```js id="8kg6of"
res.status(404).send("Not found");
```
